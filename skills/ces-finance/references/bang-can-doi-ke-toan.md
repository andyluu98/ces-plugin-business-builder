# Bảng Cân đối Kế toán (Balance Sheet) | ces-finance

## Mục đích & Phạm vi
Template này hướng dẫn Claude xây dựng và phân tích Bảng Cân đối Kế toán (Balance Sheet) theo chuẩn mực kế toán Việt Nam (VAS) và format quản trị nội bộ. Balance Sheet là "ảnh chụp" tài chính của doanh nghiệp tại một thời điểm cụ thể, cho thấy doanh nghiệp có gì (tài sản), nợ ai (nợ phải trả) và vốn chủ sở hữu là bao nhiêu. Phân tích Balance Sheet giúp đánh giá thanh khoản, đòn bẩy tài chính và sức khỏe tổng thể của doanh nghiệp. Phù hợp cho báo cáo định kỳ, chuẩn bị kiểm toán và ra quyết định tài chính chiến lược.

## Câu hỏi thu thập thông tin
1. Thời điểm lập bảng cân đối: ngày cuối tháng, quý hay năm?
2. Doanh nghiệp có tài sản cố định lớn không? Phương pháp khấu hao đang áp dụng là gì?
3. Cơ cấu vốn hiện tại: tỷ lệ vốn chủ sở hữu vs vốn vay? Các khoản vay ngắn hạn và dài hạn cụ thể?
4. Có tồn kho không? Phương pháp tính tồn kho: FIFO, bình quân gia quyền hay đích danh?
5. Khoản đầu tư tài chính dài hạn (góp vốn, mua cổ phần công ty khác) hiện có là gì?
6. Có cam kết tài chính ngoại bảng (off-balance sheet) nào cần tiết lộ không? (Bảo lãnh, thuê hoạt động...)
7. Mục tiêu Balance Sheet trong 12-24 tháng tới: tăng vốn chủ, giảm nợ, hay mở rộng tài sản?

### Phần 3: Phân tích Chỉ số Tài chính từ Balance Sheet

#### 3.1 Chỉ số Thanh khoản
| Chỉ số | Công thức | Kỳ này | Kỳ trước | Benchmark |
|--------|----------|--------|---------|-----------|
| Current Ratio | TS ngắn hạn / Nợ ngắn hạn | | | >1.5 |
| Quick Ratio | (Tiền + AR) / Nợ ngắn hạn | | | >1.0 |
| Cash Ratio | Tiền / Nợ ngắn hạn | | | >0.5 |
| Working Capital | TS ngắn hạn - Nợ ngắn hạn | | | Dương |

#### 3.2 Chỉ số Đòn bẩy (Leverage)
| Chỉ số | Công thức | Kỳ này | Kỳ trước | Benchmark |
|--------|----------|--------|---------|-----------|
| Debt/Equity | Tổng Nợ / VCSh | | | <2.0 |
| Debt/Assets | Tổng Nợ / Tổng TS | | | <0.5 |
| Interest Coverage | EBIT / Lãi vay | | | >3x |
| Net Debt | Vay - Tiền mặt | | | |

#### 3.3 Chỉ số Hiệu quả Sử dụng Tài sản
| Chỉ số | Công thức | Kỳ này | Kỳ trước |
|--------|----------|--------|---------|
| Asset Turnover | Doanh thu / Tổng TS | | |
| Receivable Turnover | DT / AR bình quân | | |
| Inventory Turnover | COGS / HTK bình quân | | |
| ROCE | EBIT / (TS - Nợ ngắn hạn) | | |

### Phần 4: Phân tích Cơ cấu Tài sản và Nguồn vốn
- Tài sản ngắn hạn / Tổng tài sản: bao nhiêu %?
- Vốn chủ / Tổng nguồn vốn: mức độ tự chủ tài chính
- Tài sản cố định được tài trợ bởi nguồn vốn nào? (Nguyên tắc: TS dài hạn phải được tài trợ bằng nợ dài hạn + VCSh)
- Vốn lưu động ròng (Net Working Capital) và xu hướng thay đổi

## Hướng dẫn cho Claude
1. Kiểm tra cân đối (Tổng TS = Tổng Nguồn vốn) là bước đầu tiên bắt buộc trước khi phân tích.
2. Diễn giải ý nghĩa các con số cho lãnh đạo không chuyên: "Current Ratio 1.2 nghĩa là gì với doanh nghiệp?"
3. So sánh 2 kỳ liên tiếp để thấy xu hướng, không chỉ nhìn vào số tuyệt đối.
4. Phân tích cơ cấu nguồn vốn tài trợ tài sản là quan trọng nhất cho đánh giá rủi ro tài chính.
5. Highlight các khoản bất thường: AR tăng nhanh hơn DT (rủi ro nợ xấu), HTK tăng (rủi ro tồn kho lỗi thời).
6. Kết nối Balance Sheet với P&L và Cash Flow để có bức tranh tài chính toàn diện.
7. Đảm bảo consistent với số liệu kế toán: số dư tiền = sổ quỹ + sao kê ngân hàng.
